# 地址与发布流程

## 统一站点规划

本应用不创建新的 Vercel 项目。统一宿主建议使用一个专用域名：

- 统一域名：`https://imagecleaner.zestgpt.com`
- 本应用根地址：`https://imagecleaner.zestgpt.com/ai_logo_creator`
- App URL：`https://imagecleaner.zestgpt.com/ai_logo_creator`
- Allowed redirection URL：`https://imagecleaner.zestgpt.com/ai_logo_creator/auth/callback`
- Privacy policy URL：`https://imagecleaner.zestgpt.com/ai_logo_creator/privacy`
- 订阅完成后的应用地址：`https://imagecleaner.zestgpt.com/ai_logo_creator/app`
- App-uninstalled webhook：`https://imagecleaner.zestgpt.com/ai_logo_creator/webhooks/app/uninstalled`
- Subscription webhook：`https://imagecleaner.zestgpt.com/ai_logo_creator/webhooks/app/subscriptions_update`
- Compliance webhook：`https://imagecleaner.zestgpt.com/ai_logo_creator/webhooks/compliance`

这些地址由现有 `shopify-app-store` Vercel 项目的多应用路由提供，不需要新域名或新项目。正式提交审核前需验证线上部署及 Shopify 内嵌工作流。

## Shopify Dev Dashboard 填写位置

1. 打开 `https://dev.shopify.com/dashboard/217457252/apps/420007182337`，进入已创建的 Zest AI Logo Creator。
2. 在 App setup / URLs 中填写 App URL 和 Allowed redirection URL。
3. 将新应用的 Client ID 写入 `shopify.app.toml` 的 `client_id`。
4. 将 Client ID、Client secret 分别配置为共用项目的 `AI_LOGO_CREATOR_SHOPIFY_API_KEY`、`AI_LOGO_CREATOR_SHOPIFY_API_SECRET`。每个 Shopify 应用必须使用自己的一组凭据。
5. 在 Configuration 中确认 embedded app、`read_products,write_products` scopes、App Bridge CDN 和 session token。
6. 在 Distribution 选择 Shopify App Store / public distribution。
7. 在 Pricing 中建立与上架文案一致的四个 public plans，再启用 Shopify App Pricing。
8. 在 Listing 中复制 `上架文案.md`，并上传 `assets` 中的图标和 feature media。
9. 安装到开发店，实际完成登录、生成、下载、写入商品图片和订阅跳转，让 Embedded app checks 收集会话数据。
10. 录制审核视频，粘贴公开视频或 unlisted YouTube URL，然后提交审核。

## 合并到统一 Vercel 前仍需完成

- 统一宿主需要按首段路径选择对应 Shopify API key、secret、app URL、session namespace 和页面入口。
- 必须保证 `/ai_logo_creator` 前缀在 Remix 页面、OAuth callback 和 webhooks 中都不会被剥离或错误重定向。
- 在目标环境中配置 `SHOPIFY_INTERNAL_API_KEY`，并确保 node_server 使用相同值。
- node_server 需要部署本次新增的 `ai_logo_creator.shopify_pricing` 配置。
- 正式上线前实测目标地址，确认没有跳到 Bulk Background Remover 或 Product Image Cleaner 的凭据和订阅。
