# Zest AI Logo Creator — English Listing Metadata

## App introduction

Turn a brand brief into an original logo. Download it or add it to a product.

## App details

Create original logo concepts for products, collections, and campaigns. Enter a brand name and creative direction, then generate a square logo inside Shopify admin. Optionally upload a JPG, PNG, or WebP reference image to guide the design.

Review the logo on a dedicated result page. Download the full-size image or add it as new product media while preserving existing images. Return to the creation page at any time to revise the brief and create another concept.

## Testing instructions

No additional account or login credentials are required.

1. Install the app on a Shopify development store and open Zest AI Logo Creator from Shopify admin.
2. Enter "Northstar Coffee" in the Brand name field.
3. Enter "Minimal mountain symbol, deep green and warm gold, premium outdoor feel" in the Creative direction field.
4. Optionally upload a JPG, PNG, or WebP reference image no larger than 5 MB.
5. Click "Generate logo concept". A successful generation uses one logo from the merchant's plan. If generation fails, the reserved logo credit is refunded.
6. Confirm that the app opens a dedicated result page after generation.
7. Click "Download logo" to test image download. "Open full size" can also be used to inspect the generated image.
8. Select a Shopify product under "Add logo to product", then click "Add as new product image". Confirm that the generated logo is added as new media and that existing product images remain unchanged.
9. Click "Back to logo creator" and confirm that the app returns to the creation page.
10. Open "View plans / Manage subscription" to verify the Shopify-managed pricing page. Development stores may display test pricing and do not create a real payout.

The app requests `read_products` and `write_products`. It does not request access to customer or order data.

Reference image files upload directly from the merchant's browser to Cloudflare R2 through a short-lived signed URL. The application server receives the uploaded image URL rather than the full file body.
